# 03. Machine Learning From Scratch

Supervised and unsupervised Machine Learning algorithms built strictly using low-level tensor/matrix operations without high-level APIs (like Scikit-Learn or PyTorch).

* **Focus Areas:** Gradient Descent variants, Linear/Logistic Regression, K-Nearest Neighbors (KNN), Decision Trees, and basic Multi-Layer Perceptrons (MLP).
* **Goal:** Demonstrating deep mathematical understanding of loss functions, backpropagation, and optimization landscapes.
